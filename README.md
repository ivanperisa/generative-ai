# Generative AI · Test 1 practice quiz

Practice questions for TU Wien 194.207 Generative AI, Test 1, covering the four lectures:
Introduction to Generative AI, Theoretical Foundations of Language Modelling, Training Paradigms I and II.

- Practice mode: one question at a time, filter by lecture, retry the ones you got wrong.
- Mock test: 20 questions, 40 minutes, scored like the test (+1.5 ÷ n per correct tick, −0.75 per wrong tick, at least 0 per question).

Everything runs in the browser. Your results are kept in your own browser's local storage and are never sent anywhere.

Unofficial study material written by students; check the lecture notes when in doubt.
